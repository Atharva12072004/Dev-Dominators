## Core Runtime Flows

### Real-time event flow

1. Native source event arrives
2. Event normalized into protection pipeline
3. Offline heuristics run immediately
4. Backend enrichment runs when network is available
5. Protection log is saved
6. Warning UI appears if threshold and source context require it

### Manual scan flow

1. User enters text and/or URL
2. Local heuristic result is available instantly
3. Backend unified scan enriches score/reasons when available
4. Threat details screen renders final result

### Browser protection flow

1. User shares or opens link through CyberShield AI
2. Local URL scan runs first
3. Backend URL reputation scan runs second
4. If risky, warning screen is shown
5. If user ignores, external browser opens
6. If blocked, content remains blocked in logs/history
